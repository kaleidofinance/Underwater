# underwater.fun — how to report a security issue.
# Format: RFC 9116. https://www.rfc-editor.org/rfc/rfc9116
#
# Why this file exists beyond the obvious: a wallet-connect page on a young
# domain has no reputation to lean on, and the automated abuse feeds that wallets
# and registries consume read the absence of a reachable security contact as one
# more point against. This is the cheapest verifiable thing a site can publish —
# a real contact, a real policy, and the hostnames that are actually ours.
#
# Contacts are HTTPS rather than an address: both are monitored, neither is a
# personal inbox, and GitHub's advisory form gives a reporter a private thread
# with a record instead of a mail that may or may not have arrived.
